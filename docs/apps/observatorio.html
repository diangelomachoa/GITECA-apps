Pérdida de cobertura arbórea (Hansen / UMD, Global Forest Watch)

El mapa muestra la pérdida de cobertura arbórea detectada con Landsat entre 2001 y el último año publicado. Usa el filtro para ver un periodo.

Pérdida de cobertura arbórea no es lo mismo que deforestación: incluye causas naturales y aprovechamiento. Para alertas tempranas oficiales del Perú consulta GeoBosques – MINAM; para alertas GLAD/RADD, Global Forest Watch. También puedes probar nuestra app de alertas RADD en Google Earth Engine.
